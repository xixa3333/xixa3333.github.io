# 王凱弘個人網站

以 Astro 與 astro-flipside 主題重構的個人作品集，內容包含經歷、競賽成果、技能、教學與專案。

## 本機開發

```bash
npm install
npm run dev
```

## 驗證與建置

```bash
npm run check
npm test
npm run build
```

網站透過 `.github/workflows/deploy.yml` 部署至 GitHub Pages。

舊版單頁網站保留於 `legacy-site/`，供資料核對使用。

## 授權

網站架構衍生自 MIT 授權的 [astro-flipside](https://github.com/nagameTW/astro-flipside)。
